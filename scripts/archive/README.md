# Archiwum skryptów

Jednorazowe skrypty z wcześniejszych etapów (stare banery, pojedyncze poprawki danych,
publikacja konkretnych realizacji). Nic ich nie wywołuje: nie ma ich w `package.json`
ani w dokumentacji. Zostają tu na wypadek, gdyby trzeba było coś powtórzyć.
Nie są indeksowane przez Graphify (`.graphifyignore`).
